A potato chip bag collection with no server of its own. GitHub Pages hands out static files, Firebase keeps the bags and photos, and a set of security rules seals the two together: anyone can look, only the collector can write.

Reading

A visitor opens chipbagger.fun

  1. 1GitHub Pages serves the files exactly as they sit in the repo: HTML, CSS, scripts, Leaflet, the map outlines and data/origins.json. There is no build step and no server code.
  2. 2bags-source.js imports Firestore Lite from gstatic as an ES module, only when the page needs data.
  3. 3It asks for bags where active == true, plus any places added from the admin. The rules let anyone read those and refuse deleted bags.
  4. 4Photos load straight from the Storage URLs saved on each bag. A missing thumbnail falls back to the full photo, then to a 🥔 placeholder.
  5. 5app.js gives every bag a place, then draws the three tabs. The map uses bundled country and state outlines, so it needs no tile server and no API key.

If js/firebase-config.js has no project ID, steps 2–4 are replaced by data/bags.csv and the photos in images/.

Writing

The collector adds or rates a bag

  1. 1Open /admin/ from the home-screen icon. sw.js keeps the page shell available offline and lets every Firebase request go straight to the network.
  2. 2Sign in with Google. The page refreshes the ID token and looks for admin: true. Any other account sees “No access” and no setup hints.
  3. 3When a bag comes from somewhere new, Nominatim turns city, state and country into coordinates, and the place is saved to places/{key}.
  4. 4The photo is drawn onto a canvas and re-encoded twice: 1200px and 360px JPEGs. Canvas output carries no EXIF, so the phone’s GPS location never leaves it.
  5. 5Both files upload to Storage under bags/ and thumbs/. When a photo is replaced, the old files are removed afterwards.
  6. 6The bag document is written. The rules check the admin claim, the allowed fields, text lengths and 1–10 scores. Save & next opens the next unrated bag; Delete only sets active to false.

Operating

One-off jobs from Dan’s laptop

  1. Agrant-admin.mjs puts the admin claim on a Google account that has signed in once. This is the only way to become an admin.
  2. Bmigrate.mjs copied the 170 bags in bags.csv into Firestore and their photos into Storage, resized with sharp and stripped of EXIF. It skips bags already there, so it is safe to re-run. rename-originality.mjs moved the old collectability score to originality.

These scripts use the Admin SDK and a service-account key, which bypass the rules entirely. That is why the key lives outside the repo. For testing, the same scripts and both pages run against local Firebase emulators.

How a bag finds its pin

Every bag on the Chip Map is placed by placeFor() in app.js. Brand locations are each company’s home base or main plant, not necessarily the plant printed on the bag.
